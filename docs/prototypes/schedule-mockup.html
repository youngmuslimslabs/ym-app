Dialog → empty editor
Flow: Click + New conference on the dashboard → shadcn Dialog collects minimum info (name, dates, timezone) → submit inserts the conferences row and redirects to /admin/schedule/{id} on the Schedule tab's empty state. Everything else (sessions, attendees, passwords) is built iteratively in the editor's tabs.
