Admin Schedule UX — 3 Approaches Click each option to explore the interaction pattern
Recommended
Persistent split panel — list on the left, detail+edit panel always open on the right. Clicking a session loads it in the panel instantly — no open/close ceremony, no lost scroll position. Edit happens inline in the panel: view fields become inputs. Roster visible below the edit form in the same panel.
No modals Fastest session-hopping Roster + edit in one place List area is narrower
Option B
Rich cards + slide-in sheet — full-width cards that show all session info (speaker, room, capacity bar, description excerpt) without clicking. Editing opens a sheet from the right edge. Sheet holds the edit form and roster as separate sections.
Maximum info at a glance Sheet > modal (less disruptive) Cards are tall (fewer visible) Sheet open/close still has friction
Option C
Lean rows + sheet (smallest change from current) — keeps the compact list but replaces the modal with a sheet, and merges roster + editing into that sheet. One interaction instead of two competing ones (currently: click body → roster, click edit icon → modal).
Familiar list density Unifies roster + edit Sheet still disrupts context No improvement in scanning
