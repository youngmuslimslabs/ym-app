Published mode: Schedule IS the page — no tabs. Info / Attendees / Feedback live as icon buttons in the header (with the count or response indicator inline) and open as Sheets. Only the primary action ("Add session") and one secondary ("Preview as attendee") earn full button treatment. Sticky day headers are pure information — title + counts only, no action buttons. Destructive confirmations — type to confirm

canonical pattern for all destructive deletes
17a · Delete session

Delete this session?

Permanently removes "The Ethics of Community Building" and all 32 signups, 21 check-ins, and 18 feedback responses. This cannot be undone.

17b · Delete conference

Delete this conference?

Permanently removes National Convention 2026, 18 sessions, 1,240 attendee invitations, and all signups, check-ins, and feedback. This cannot be undone.

All destructive deletes use the same type-to-confirm pattern. Sessions require typing delete; conferences require typing the full conference name (higher blast radius = stricter guard). Same dialog component, just different confirmation strings.
